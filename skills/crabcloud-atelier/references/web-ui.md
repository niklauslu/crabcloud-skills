# Atelier 网页操作指引（Web UI 速查）

用户问「网页上在哪里操作 / 点哪里 / 哪个 tab」时按此指路（CLI 主管道与
自动化见 SKILL.md；本文只管 Web 的页面位置）。

站点：**atelier.crabcloud.cc**——用 Crab Cloud 主站账号直接登录（cookie 根域
共享，crabcloud.cc 登录一次全站通用）。没有工坊时登录页会给开通引导（申请-
审核制，通过扣 1 积分）；受邀成员走邀请链接 `/join/:token` 入坊；工坊邀请码
注册的新账号免邮箱验证。

## 页面地图（顶部四板块）

| 页面 | 在这里做什么 |
|---|---|
| **工作台** `/` | 款式统计带（总数/进行中/打样中/完成）、快捷操作卡（新建款式）、资源卡（系列/供应商速览）、最近动态 |
| **产品库** `/products` | 款式画册：**刊头数据带**（在库/各阶段/已归档/全部的计数即筛选——点数字筛、再点取消）+ 搜索 + 系列可搜索下拉 + 新建款式；顶栏图标切**网格画册 ↔ 列表**双形态（偏好记住）；点卡片进详情，**点封面开灯箱看大图**（封面加载中出骨架+loading，失败出款号占位） |
| **记录** `/records` | 三个 tab：**系列批次**（建档/归档/恢复）/ **供应商**（面辅料商家、加工厂）/ **研发记录**（全工坊事件流：全部/打样/核价/制单/入库/采购/备注筛选） |
| **设置** `/settings` | 四个 tab：**工坊**（名称/品牌名/标识）/ **成员**（调权限/移出）/ **岗位与权限**（岗位名录 + 新成员默认权限）/ **邀请**（常驻链接 + 二维码，下载/重置） |

## 款式详情：五个流程 tab（核心工作面，`?tab=` 可深链）

产品库点任意款式卡进入。自左到右：

| tab | 在这里做什么 |
|---|---|
| **信息** | 四组：01 基础信息（编辑抽屉）/ 02 商品规格（色板 + 尺码）/ 03 生产信息（特殊工艺）/ 04 尺寸表（部位 × 尺码矩阵内联编辑）。各组独立「编辑」 |
| **打样** | 三类稿件（**设计稿 / 纸样稿 / 样衣稿**：传图即当前稿，点图开灯箱）；「添加审版」抽屉展示当轮稿件 + **打印预览**；审版 = 通过/不通过 + 备注，通过则当轮稿件各 +1 版；审版记录条目可按条打印；**误操作走记录条目「撤回」**（仅最新一条可撤，需确认：通过单的稿件回到待审可改后重审，记录保留「已撤回」标记并隐藏打印，撤回落时间线） |
| **核算** | 面辅料段 / 工艺段 / 其他成本行（各带添加抽屉，供应商选择器可快捷建档）→ 成本汇总四卡 + **打印核算单**（A4） |
| **制单** | 制单列表（状态筛选 chips）：**添加制单**抽屉按「色 × 码」矩阵填数量 + 工序（默认裁剪/车缝/后整/质检可改）+ 加工厂 + 预计交期；行操作：草稿 = 编辑/确认/作废，已确认 = **打印工艺单**/作废；已确认行带报数/入库只读摘要 |
| **生产** | 顶部**选单 chips**（已确认制单）→ **工单头速览卡**（单号/件数/加工厂交期 + 工序报数进度 + 入库对账）→ 三板块**上下平铺**（2026-10-12 合流拍板，非 tab 切换）：**01 采购**（物料对账段：应买/已买/余缺/实付合计 + 采购流水；「记一笔采购」抽屉选物料〔确认时点核算清单〕+ 供应商 + 数量 + 实付金额；到货/编辑/删除行内操作）→ **02 报数**（「报数」弹窗：工序 + **色 × 码矩阵逐格填数**〔合计自动算，单据没订的格子「—」禁填，超量二次确认〕→ 报数流水）→ **03 入库**（按当前单登记回货，对账见工单头；全部回齐出提示条，**一键标记款式完成**；回货流水） |

## 打印单据（都开新窗口出 A4）

| 单据 | 入口 | 说明 |
|---|---|---|
| 工艺单 | 制单 tab 行内「打印工艺单」 | 仅已确认制单可出；**不含任何金额**（纯工艺指令，给工厂） |
| 核算单 | 核算 tab「打印核算单」 | 三张分项表 + 单件合计 + 签字栏 |
| 审版记录单 | 打样 tab：审版抽屉「打印预览」（未提交意见也能出）或已提交记录条目「打印」 | 按单条审版记录出单 |

## 常见意图 → 操作位置

| 用户想… | 去哪里 |
|---|---|
| 新建一款 / 改款号品类设计师 | 产品库「新建款式」/ 详情信息 tab「编辑信息」 |
| 补色板尺码 / 录尺寸表 / 填特殊工艺 | 详情信息 tab 02 / 04 / 03 组 |
| 传设计图、纸样、样衣照片 | 详情打样 tab（选对应类型上传） |
| 审版拍板、出审版留档单 | 详情打样 tab 审版区 |
| 核单件成本、出核算单 | 详情核算 tab |
| 排产、给工厂出工艺单 | 详情制单 tab（建档 → 确认 → 打印） |
| 记今天生产做到哪道工序 | 详情生产 tab「02 报数」板块 |
| 登记工厂回货、看差数、款式收尾 | 详情生产 tab「03 入库」板块（差数 = 未交尾数；回齐可标记完成） |
| 记面辅料采购、看应买已买余缺、标记到货 | 详情生产 tab「01 采购」板块（物料取自确认时点核算清单） |
| 建系列批次 / 供应商 | 记录页前两个 tab |
| 加人 / 调权限 / 建岗位 / 发邀请 | 设置页（邀请 tab 出常驻链接和二维码） |
| 查「这款做过什么」全历史 | 记录页研发记录 tab（按类型筛）或款式时间线 |

## 权限速查（写操作按成员权限放行；owner 直通，active 成员可读全部）

| 权限项 | 覆盖的 Web 操作 |
|---|---|
| styles | 款式建档/编辑、商品规格、尺寸表、打样稿件上传、审版 |
| materials | 核算面辅料行 |
| costing | 核算工艺行 / 其他成本行 |
| production | 制单（建/编辑/确认/作废）、报数、入库登记、采购登记 |
| team | 成员调整、邀请 |
| settings | 工坊信息、岗位名录、新成员默认权限 |

按钮级表现：无写权限时对应「新建/编辑/报数」入口直接隐藏（不是置灰）——
用户说「看不到按钮」时先核对成员权限，再核对是否进对了工坊（顶栏有工坊
切换器）。
